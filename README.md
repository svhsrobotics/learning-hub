# Saucon Valley Robotics Learning Hub

The website for all three Saucon Valley FTC teams (Gamma, Psi and Robotica): the BIOBUZZ game, the robot, the code and the tools. It's for every team member, whether you build, code, drive or do outreach.

**Open the hub:** https://svhsrobotics.github.io/learning-hub/

## What's in it

| Section | What you'll find |
|---|---|
| Overview: Field and Rules | The BIOBUZZ field, scoring and key rules, in drawings |
| Latest updates | News for the whole program, newest first |
| Team links | Links the teams use |
| Coding | Java basics, your first OpMode, getting code onto the robot, sample code |
| Your tools | Laptop setup, the simulator, Git and GitHub |
| Glossary | FTC and coding words in plain English |

## How it works

Each page is a Markdown file in this repo: `home.md` is the Overview, `_sidebar.md` is the menu, and the `coding` folder holds the Coding and Your tools pages. [Docsify](https://docsify.js.org/) turns the files into web pages in your browser, and GitHub Pages publishes whatever is on `main`, usually within a couple of minutes.

## Found a mistake?

Open an issue on this repo, or send a pull request. The official Competition Manual always wins over anything here.

## It's public

Anyone can read this site and its full history. No last names, contact details, photos of people, passwords or logins.
