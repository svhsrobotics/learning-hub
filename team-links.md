## More for builders

For whoever designs, builds or inspects the robot, and for setting up a practice field.

### Example robots to learn from

FIRST works with several companies on "StarterBots": simple robots that can play this year's game. They're worth studying even if your team builds its own design, because they show one working answer to each part of the game. The rules allow using their parts as they come.

| Link | Why you'd open it |
|---|---|
| [goBILDA StarterBot build instructions (PDF)](https://www.gobilda.com/content/user_manuals/3200-2627-0003_assembly-instructions.min.pdf) | Step-by-step pictures of how goBILDA's example robot goes together |
| [goBILDA StarterBot CAD files (download)](https://www.gobilda.com/content/step_files/3200-2627-0003.zip) | The 3D model, to open in a CAD program and measure |
| [REV StarterBot](https://www.revrobotics.com/duo/ftc-starter-bot/) | REV's example robot, a different design from goBILDA's |
| [REV StarterBot build guide (PDF)](https://www.revrobotics.com/content/technical-resources/DUO/FTC-Kickoff-Concepts/2026-27/2026-27%5FREV%5FDUO%5FFTC%5FStarter%5FBot-Build%5FGuide%5F1567.pdf) | Step-by-step build for REV's robot |
| [REV StarterBot in Onshape](https://cad.onshape.com/documents/9cb9eb90e973fd37d10ee178/w/b9c02b0f4e09998f08becbd2/e/a55c018c62564f3ea8812a47) | REV's 3D model (needs a free Onshape account) |
| [REV Kickoff Concepts](https://docs.revrobotics.com/ftc-kickoff-concepts) | Ideas for intakes, launchers and other parts for this game |

### Getting through inspection

Every robot is checked by an inspector before it can play. These help your robot pass the first time.

| Link | Why you'd open it |
|---|---|
| [Inspection Quick Reference](https://ftc-resources.firstinspires.org/ftc/archive/2027/event/inspection-reference) | A short summary of what inspectors check, including which servos are already approved |
| [Robot sign template (PDF)](https://ftc-resources.firstinspires.org/ftc/team/robotsign-us) | Printable team-number signs. Every robot must show its number on its alliance color |
| [Static electricity and the robot](https://ftc-resources.firstinspires.org/ftc/team/esd-mitigation) | The foam field tiles build up static, which can upset the robot's electronics. How to protect against it |
| [All FIRST build resources](https://ftc-resources.firstinspires.org/ftc/team) | FIRST's full page of building help |
